# NodeSeek 每日热贴推送与控制面板 (NodeSeek Daily Digest)

本工具是一个部署在 Linux 服务器（如 Debian 12）上的轻量级 NodeSeek 论坛热帖精选分析与推送程序。升级后，它集成了 **Web 控制大盘、精选 Feed 阅读器、APScheduler 定时任务调度中心、SQLite3 数据库** 以及 **一键交互式安装脚本**，既可以通过 Telegram 机器人每日接收订阅推送，也可以在本地网页上直接像刷官网一样舒适阅读高人气热帖。

---

## ✨ 项目功能特性

*   🛡️ **JA3 浏览器指纹过 CF 盾**：基于 `curl_cffi` 库，从底层模拟 Chrome 浏览器的 TLS/JA3 指纹和 HTTP/2 协议特征，安全绕过 Cloudflare 5秒盾和高强度反爬拦截。
*   🎛️ **板块热度权重自定义微调**：内置 13 个独立分类板块权重滑块（Range Slider），用户可设定 `0.0 ~ 2.0` 的权重因子，使特定分类（如技术）加权高亮，或直接对水帖较多的板块（如沙盒、贴图）进行零加权过滤屏蔽。
*   ⏳ **多模型时间热度衰减系统**：首创结合平滑保护区（前 4 小时完全不衰减）的时间衰减机制，提供**希尔双曲 S 曲线 (Hill Equation - 默认)**、指数衰减、重力衰减与线性消退等 4 种动力学数学模型。保障 24h、3天、7天内的热帖高热度呈现，避免旧帖和历史高热帖长期刷屏占榜。
*   🤖 **AI 语义筛选与帖子摘要**：集成符合 OpenAI 规范的 API 端点（兼容 DeepSeek、OpenRouter、OneAPI 等），支持通过自定义自然语言 Prompt 进行 AI 语义过滤筛选；同时支持自动深度拉取 Top 热帖正文和前 5 条精彩跟帖，提炼生成 100 字以内的高密度 AI 智能摘要。
*   💬 **Telegram 双向交互式负反馈**：向 Telegram 推送时自动附带 Inline Keyboard 交互式键盘。后台采用长轮询（Long Polling）守护线程，支持直接在聊天中点赞 `👍`、点踩 `👎` 微调分类权重，或按 `🚫 屏蔽作者` 一键拉黑作者 UID，提供已操作按钮动态视觉锁定确认（如显示为 `已赞`、`已踩`，禁用同排按钮）。
*   🌐 **本地精选 Feed 阅读器**：配备极致精美的 Premium UI 主题界面与动效，完美适配移动端。左侧为卡片式历史热帖列表，右侧直接渲染净化过的正文（支持 HTML、图片与代码块排版）与热评，并在顶部展示 AI 摘要卡片。
*   🔑 **NodeSeek 登录态 Cookie 注入**：支持在网页后台直接更新账号 `cookie`，由爬虫自动携带访问，完美解锁各种“高等级限制/仅登录可见”的技术分享帖。
*   🚫 **无意义灌水帖过滤**：自定义过滤词（如“抽奖”、“送码”、“送鸡腿”等）配合板块权重，双重拦截低质帖子。
*   📦 **一键系统服务托管守护**：配备极简的 `deploy.sh` 交互式脚本，自动检测 Python3 虚拟环境，支持端口自选或随机空闲端口，将服务一键注册为 `systemd` 系统服务进程，实现开机自启、重启与卸载管理。

## 🚀 一键式交互安装步骤

登录您的 Debian 12 服务器，按顺序运行以下命令即可：

```bash
# 1. 克隆项目仓库到服务器本地
git clone https://github.com/chillpoints/nodeseek-daily-digest.git
cd nodeseek-daily-digest

# 2. 以 root 权限运行一键部署脚本
sudo bash deploy.sh
```

### 交互脚本功能：
运行后将弹出交互式菜单，输入 `1` 即可开始自动配置安装：
*   脚本会自动检测并补全 Python3 及 pip 虚拟环境环境。
*   提示您输入运行端口。如果直接按回车，系统将**随机选择 20000 到 30000 之间的空闲端口**。
*   自动创建虚拟环境隔离全局 Python 依赖，安装 `requirements.txt`。
*   将网页后台注册为 `systemd` 系统服务进程，自动开机自启。
*   输出控制面板的 Web 登录链接（例如：`http://YOUR_SERVER_IP:PORT`）。

## ⚙️ 网页控制面板使用说明

打开部署输出的网页地址（如 `http://服务器IP:端口`）：

1.  **Dashboard（控制台）**：
    *   **核心状态概览**：展示当前自动调度频率、爬虫指纹引擎、Telegram 订阅及推送是否开启。
    *   **控制台日志输出**：配合“实时日志控制台”，可直接点击 **“立即运行抓取”**，后台抓取、AI 语义判定过滤、正文爬取、AI 摘要提炼及 TG 消息推送的所有细节都将在控制台滚动输出。
2.  **Settings（参数配置）**：
    *   **Cookie 注入**：填入您的 NodeSeek `cookie` 解锁高等级限定帖子。
    *   **Telegram 订阅**：填入 Bot Token 和 Chat ID。推送信息中将自动携带交互式的点赞、点踩和拉黑 Inline 按钮。
    *   **时间热度衰减**：选择时间衰减模型（默认首选希尔双曲 S 曲线），通过滑块自由调整保鲜期、折半半衰天数、重力系数等。
    *   **AI 辅助配置**：开启后填入 API Key、Base URL 以及模型名（如 `gpt-4o-mini` / `deepseek-chat`）。可分别控制是否开启 AI 帖子筛选（填入自定义 prompt 过滤内容）和 AI 热帖内容摘要。
    *   **权重微调**：拖动 13 个板块的范围滑块来微调加权分数。
3.  **Feed Reader（精选阅读）**：
    *   数据将持久化记录在 SQLite 数据库中。
    *   左侧列表展示已抓取的热点帖子，右侧展示详情。如果开启了 AI 总结，会在详情最上方渲染带有机器人图标的 **AI 智能提炼摘要卡片**，让您用最快的时间筛选吸收高密度内容。
